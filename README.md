#UTS Pemrograman Web - Aplikasi Biodata Tim
Aplikasi web interaktif untuk mengelola data profil dan biodata anggota tim secara dinamis. Proyek ini dibuat sebagai tugas Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web dengan mengimplementasikan operasi **CRUD** (*Create, Read, Update, Delete*) serta fitur manajemen foto fleksibel menggunakan HTML, CSS, dan JavaScript.

#Fitur Utama
* **Tambah Biodata (Create):** Menambahkan data anggota tim baru melalui form modal **Tambah Biodata** (mencakup input Nama Lengkap, Deskripsi / Peran & NIM, serta foto).
* **Tampilan Kartu Dinamis (Read):** Menampilkan daftar biodata anggota tim dalam bentuk kartu (*card*) yang rapi dan responsif.
* **Edit Biodata (Update):** Memperbarui informasi biodata maupun mengganti foto profil anggota yang sudah tersimpan.
* **Hapus Biodata (Delete) dengan Konfirmasi:** Menghapus data anggota dilengkapi kotak dialog **Konfirmasi Hapus** (*"Yakin ingin menghapus biodata ini?"*) untuk mencegah penghapusan yang tidak disengaja.
* **Opsi Foto Ganda:** Mendukung pengisian foto melalui **URL Foto** maupun **Unggah Foto langsung dari perangkat** pengguna (dilengkapi gambar *placeholder* bawaan jika dikosongkan).
* **Notifikasi Interaktif:** Menampilkan pesan umpan balik status secara langsung setelah setiap aksi dilakukan (seperti *"Biodata berhasil diperbarui."*).

# Teknologi yang Digunakan
* **HTML5:** Struktur halaman web, navigasi (*Home, Features, Pricing, FAQs, About*), serta form modal input dan konfirmasi.
* **CSS3:** Pengaturan tata letak responsif (*card grid*) dan desain antarmuka pengguna (UI).
* **JavaScript:** Logika pengelolaan data CRUD, manipulasi DOM dinamis, pembacaan file foto lokal maupun URL, serta sistem notifikasi.
